# Landing Page Wireframe

## Purpose
Simple landing page for a learner portal with clear calls to action.

## Layout
+--------------------------------------------------------------+
| SkillsTrack                                                   |
| Home | Features | About | Sign In | Create Account            |
+--------------------------------------------------------------+
| Hero section                                                  |
| Welcome to SkillsTrack                                        |
| Manage tasks, track progress, request support                 |
| [Sign In] [Create Account]                                    |
| Card showing: Completed Tasks | Outstanding Tasks | Progress |
+--------------------------------------------------------------+
| Feature cards                                                 |
| Task Management | Progress Tracking | Support Booking          |
+--------------------------------------------------------------+
| Footer                                                        |
| Contact | Privacy | Help                                      |
+--------------------------------------------------------------+

## Notes
- Primary CTA is Create Account.
- Navigation should remain simple and mobile-friendly.
- Hero card should highlight productivity status.
